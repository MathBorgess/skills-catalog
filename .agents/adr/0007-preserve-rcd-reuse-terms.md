The source terms require attribution to Richard (@richardrx), preservation of the complete terms and a restriction on gambling/betting/casino use; they must not be represented as MIT.

Keep the existing MIT material under its current license. Ship the complete RCD terms with the adaptation and a package license map identifying the affected instructional files, distinguishing original helpers from adapted material. Make the README and package metadata describe that composition accurately. This keeps the operator's commercial-design reference available at execution time while preserving conditions that cannot be erased from already-distributed copies by a later catalog edit.
