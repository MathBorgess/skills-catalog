# Viral formats and angle engineering (`viral-rag`)

Use this reference in Step 2 to select a short-form format archetype and sharpen a generic topic into a high-retention angle. Also check `<project>/references/viral-rag/` when present for project-specific reference cards.

## The six short-form format archetypes (20s–60s)

| Archetype | Core mechanism | Beat timeline (typical 30s) | Best for |
|---|---|---|---|
| **1. Proof-First Demo** (*Projeto de Bolso*) | Show the working result or failure at `0–3s`, then rewind to the minimum mechanism that produced it | `0–3s` Result/Failure Hook -> `3–8s` The concrete problem -> `8–22s` 3 build/mechanism beats -> `22–27s` Honest trade-off/limit -> `27–32s` Reproducible first step / CTA | Technical builds, product demos, workflows |
| **2. Test with Real Friction** (*Deixa Eu Testar*) | Test a tool, claim, or workflow on screen, keeping the exact moment it broke or needed a fix | `0–3s` Expectation vs. Reality Hook -> `3–9s` Setup & rule of the test -> `9–20s` Live attempt + where it choked -> `20–26s` The fix / verdict -> `26–30s` Who should actually use it | Tool reviews, experiments, benchmarks |
| **3. Two-Tab Contrast** (*Duas Abas / Myth-Busting*) | Put the common belief or default way side by side against the engineered alternative | `0–3s` Contrarian / Split Hook -> `3–10s` Tab A (what everyone does & hidden cost) -> `10–22s` Tab B (the structural change & proof) -> `22–27s` Side-by-side delta -> `27–30s` Open question for comments | Architecture comparisons, myth-busting, before/after |
| **4. Problem-Agitate-Solve (PAS)** | Name a specific pain, expose the real cost of ignoring it, and land one sharp shift | `0–3s` Call-Out / Pain Hook -> `3–10s` Agitate the hidden cost -> `10–22s` The mechanism that solves it -> `22–27s` Concrete example -> `27–30s` CTA or Seamless Loop | Educational hooks, consulting insights, mindset shifts |
| **5. Story-Lesson** (*Bastidor / Falha Real*) | One dated, concrete incident (a bug, a mistake, a client moment) that teaches a transferable principle | `0–3s` Incident Hook (in media res) -> `3–12s` Escalation & what went wrong -> `12–22s` The turning point / discovery -> `22–28s` The rule extracted -> `28–32s` Loop back to hook | Build-in-public, founder stories, post-mortems |
| **6. Ranked Escalation** (*Tier / 3 Levels*) | Escalate from level 1 (common/weak) to level 3 (uncommon/high-leverage) so viewers stay for the top tier | `0–3s` Escalation Hook -> `3–10s` Level 1 (baseline) -> `10–18s` Level 2 (better, with trade-off) -> `18–26s` Level 3 (the real unlock) -> `26–30s` Save/share cue | Frameworks, tool stacks, skill progressions |

## Angle sharpening rules

A topic ("how to use AI agents") is not an angle. An angle has **tension, specificity, and stakes**:

1. **Attach a concrete noun or number:** Replace "faster" with the observed time, file count, or failure rate.
2. **Name the enemy or friction:** Every strong short-form angle pushes against a default habit, a false promise, or a real constraint.
3. **Standalone Series Rule:** If the video is part of a multi-part series, never frame the angle as "Part 2 of yesterday's video." Anchor it on one self-contained transformation, failure, or decision that a cold viewer understands in 3 seconds.

## Project-local `viral-rag` cards (`<project>/references/viral-rag/`)

When the user's project contains `.md` or `.json` files under `references/viral-rag/`, scan them by format, hook trigger, or tag before recommending an angle. Each card records:
- `archetype`: one of the formats above
- `hook_triad`: `{ visual, on_screen_text, spoken, trigger }`
- `beat_cadence_sec`: average beat length and reset pattern
- `why_it_worked`: the transferable retention mechanism (never copy another creator's topic or wording verbatim; transfer only the structural mechanism).
