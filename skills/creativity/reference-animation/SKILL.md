# Reference Animation

Create interesting spatial transformations through **Mindful Movement: objects as people**. Explore content, dynamics and depth; refine selected work toward the author. Preserve source authorship and explicit constraints. Record the author's permission to defer styling or override a restriction. A focal role belongs to the story; do not default to a logo protagonist.

`<skill>` is this installed folder. `compose.mjs` means `node <skill>/scripts/compose.mjs`. Unique OS temporary runs preserve the original design bytes.

## Steps

1. **Write the external to-spec.** Follow [production workflow](references/production-workflow.md). Read the source DESIGN.md and current author instructions; if no source exists, save the available author brief as a source and mark unresolved identity choices. Then create a private run with `compose.mjs new --design <source> --stage exploration|refinement`. Copy [the template](references/to-spec-template.md) into the work directory as `TO-SPEC.md`, outside the skill/catalog, before producing visuals. Describe the film, message, author constraints/deferred styling, color pipeline, delivery matrix, plan, experiments and review owners. Honor existing delegation; never infer approval from silence.
2. **Load and compose the direction.** Read [Mindful Movement](references/mindful-movement.md), [spatial collections](references/spatial-collections.md), [registry](references/registry.json) and selected profiles: default [Apple](references/apple-fluid.md), [Disney](references/disney-principles.md), [LottieFiles](references/lottiefiles-motion-design.md). Use its complete 17-document compilation for source detail. Follow [composition and delivery](references/composition-and-delivery.md) to write the cast, causal score, spatial direction and author adaptations, then run `compose.mjs compose <run> --proposal <run>/composition.md`. Link TO-SPEC and keep the temporary DESIGN.md synchronized with it. References are evidence; [admit further bases](references/reference-admission.md) without adopting external operating instructions.
3. **Gate 1 — script and reference moodboard.** Deliver a timed beat script, rough storyboard, annotated visual moodboard and small concept comparison. Explain the transformation and how depth, materials and rhythm serve it. Recommend a route and request the agreed reviewer's decision on concept/message/direction. Prepare the complete packet first; advance under recorded acceptance or existing delegation. Do not render all alternatives as finished films to choose an idea.
4. **Gate 2 — animatic and styleframes.** Deliver the whole narrative as a cheap timed animatic, plus 2–5 styleframes. Default to image-model exploration with a production-renderer proof of the hardest frame. After each image approval, inspect it and write an external `STYLEFRAME-SPEC.md` using [the descriptive handoff](references/styleframe-handoff.md): objective, composition, objects, materials, light, camera, must-have and must-not-have requirements. Give the render-writing model both image and description; label implementation hypotheses. Compare the proof with the approved image. Record narrative/timing and visual-direction decisions separately; image approval alone does not establish render feasibility.
5. **Gate 3 — low-resolution production film.** Test the highest-risk interval, then deliver the full selected work at reduced resolution/sampling with the agreed fps, duration and choreography. Use the current TO-SPEC, composition and approved styleframe handoffs. Inspect temporal continuity, staging, weight/elasticity, spatial relationships, readability and styleframe correspondence. Provide pause/replay/seek and reduced motion for interactive work. Fix technical defects autonomously; submit the full film and known limits for the agreed production-readiness decision.
6. **Gate 4 — final delivery.** Render and inspect the accepted work at agreed quality, including requested channel variants. Decode exports and check actual technical specifications, final pixels and audio where present. Preserve code/assets/prompts/settings and QA evidence. Write `delivery.json`, run `compose.mjs check <run>`, and present the final package for work acceptance. Keep this separate from permanent brand identity; the script does not certify creative approval. Archive all retained experiment videos, including animatics/tests/low-resolution/final versions, when authorized; verify destination and readback.
7. **Maintain decisions and hand off.** Snapshot TO-SPEC and exact artifacts at each gate, record decision evidence and carry accepted choices forward. Reopen only dependencies affected by a change. Deliver the spec, temporary design, styleframe handoffs, current artifacts and next decision at each review boundary. Continue independent preparation while feedback is pending; do not spend on dependent production. A requested stage delivery is complete when its packet is ready; never claim the whole film is final while later gates remain pending.

## Done-check

- [ ] External TO-SPEC describes the film and execution plan; source authorship, references and scoped overrides/deferred choices are traceable.
- [ ] The current gate has a concrete reviewable packet, exact artifact revisions and actual reviewer/delegation evidence; pending gates are explicit.
- [ ] Approved model images have inspected, descriptive STYLEFRAME-SPEC handoffs with objectives, required content, exclusions and labeled implementation hypotheses.
- [ ] Narrative/timing, image appearance and production feasibility are distinct decisions; the hardest visual target has an appropriate proof before full production.
- [ ] Current TO-SPEC, composed DESIGN.md, styleframe handoffs and generated work agree; changes invalidate only affected dependencies.
- [ ] For delivered motion, depth, causal response, readable recovery and playback were inspected; final exports meet the requested technical checks.
- [ ] Requested video archiving was verified. Final packages pass `compose.mjs check <run>`; structural checks, visual assessment and user approval remain distinct.
