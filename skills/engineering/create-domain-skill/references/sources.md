# Origin and format sources

- [Richard's X post](https://x.com/richardrx/status/2112650627767574558): inspiration for assigning an agent a function, informing its working personality with domain practitioners, and deriving skills from their public work. Direct X access was blocked during design; a matching passage was available in an [indexed profile mirror](https://community.twstalker.com/richardrx). The mirror does not independently establish the exact status ID or provide a detailed validation protocol.
- [Agent Skills specification](https://agentskills.io/specification): portable package format, activity-focused names and descriptions, relative references and progressive loading.
- [Evaluating skill output quality](https://agentskills.io/skill-creation/evaluating-skills): practical cases, comparable baselines, saved outputs, evidence-based grading and iteration.

The activity-based public interface, source-to-method records, portable personality profile, complementary critique lenses and bounded validation loop are this catalog's implementation of the user's brief. They are not quoted instructions from the X post or claims of endorsement by its author or any researched practitioner. Research the actual activity's sources on every factory run; these format references do not establish expertise in that activity.
