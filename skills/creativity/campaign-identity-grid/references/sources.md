# Sources

The grid spec is the technique of one public post by [@AmirMushich](https://x.com/AmirMushich), rewritten as a spec, an inspection table and a fallback route. The original prompt is his; read it at the link.

| Part | Post | What was taken |
|---|---|---|
| Layout, wall rules, block types | [Asymmetric grid poster design](https://x.com/AmirMushich/status/2011079586465935747) | Five-row, two-column layout with full-width and paired rows; full bleed and zero gaps; one typeface; unique photos; logo, slogan and halftone photo blocks with their textures |
| Why Route B exists | The same thread | The author reports the model gets layout structure, slogans and content distribution wrong, and that tuning the prompt did not fix it |

Route B and the expected/seen table are additions of this catalog, not part of the source.
