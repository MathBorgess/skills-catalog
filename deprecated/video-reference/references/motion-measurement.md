# Measure movement for reconstruction

Load this for chart assembly, card movement, kinetic text, fast transitions or an audio/visual timing dependency. Pair it with [local audio analysis](local-audio-analysis.md) when sound matters.

1. **Keep source PTS.** Decode every frame in the critical interval without a frame-rate conversion. Record dimensions, PTS and frame count. Use full-video frame differences to locate candidate changes; a large difference can be a cut, flash, camera move or overlay. Frame count verifies processing, not semantic inspection.
2. **Name the moving part.** Inspect frames and choose a bounded region of interest. Record coordinates and analysis scale. Isolate the overlay from the speaker/camera where possible. Color masks, connected components and template tracking can work for flat bars, borders or badges. Optical flow is an optional tool for less separable objects, not proof of a specific CSS transform.
3. **Check the tracker.** Review start, peak, settling and failure frames. Preserve missed detections as null; do not interpolate across cuts or occlusion without marking the inference. Exclude labels from a bar-height mask. Track both top and bottom so a moving chart is not mistaken for bar growth. Coordinate clipping can falsely make an animation appear settled.
4. **Extract states and timing.** Report initial state, first change, rise, maximum extent, overshoot, settle/hold and exit. Record position/size/opacity proxies and component order. Define the pixel tolerance and hold duration for a settling measurement. Include frame quantization and segmentation error. A bar can overshoot and recoil; a card can translate while shrinking; sparse samples can miss both.
5. **Describe a recipe separately.** Measurements constrain reconstruction, but do not reveal the original easing, font, spring constants or editing software. Fit or propose an ease only as a hypothesis. Give the editor key states and tolerances first. Keep measured original anchors distinct from chosen render timings.
6. **Link dependencies and save.** Relate object entrances/landings to verified speech/effect anchors. Preserve required dependencies across layer retrieval. Store trajectories, inspected frame paths and hashes with the private reference; keep the public skill generic. Leave unreviewed movement spans explicit rather than marking a whole video watched because a frame-difference pass finished.
