# Generic walkthrough: review, revision and missing capability

This is a synthetic example, not a report of real Flow generation or human approval. A generic authored brief asks for an illustrated circle to offer a square a place to rest; its design protects their recognizable silhouettes. No private project files, account identifiers or archive links are used.

## Rejection → refinement → resubmission → acceptance

1. Save the human brief, snapshot it with DESIGN.md, write TO-SPEC and compose the direction. Moodboard v1 contrasts a soft supportive encounter with a sharp percussive exchange; it includes inspected source images and annotations.
2. Submit the exact moodboard packet. The human rejects v1: “The sharp route overwhelms the supportive message; refine the softer route.” Record decision and criticism against v1. Storyframe generation remains blocked because moodboard acceptance is pending.
3. Update TO-SPEC, preserve v1, refine the hierarchy and submit moodboard v2. A response saying only “approved” leaves criticism missing. Obtain the explicit comment: “The intention reads clearly; nothing to change.” Record both against v2.
4. Generate one storyframe through the user's chosen image tool. Inspect it, preserve its inputs/settings and present the attempt. A response with criticism alone does not accept it; get the explicit accept/revise decision. After acceptance write its descriptive STYLEFRAME-SPEC. Repeat only after the previous visual attempt has been reviewed.
5. Submit the complete storyframe/styleframe packet, then the ordered timed storyboard, each with separate human decision and criticism. Map shot-01 to the accepted image inputs and handoff.
6. Submit one gflow I2V request for shot-01. If the CLI returns successful generation but no verified local file, record it as uncertain and retain the media ID. Review the report and recover the same download before proposing another generation. Recovery creates a new outcome revision of the same attempt; the downloaded clip still needs inspection and human review.
7. Assemble the reviewed clips and agent-managed sound into the complete preview. Present it for motion-preview decision/criticism. After acceptance inspect final export and submit final delivery. Individual clip approval does not replace either assembled-film review.

## Changed dependencies

A storyboard timing revision preserves unchanged styleframe appearance. It makes its dependent shot/preview decisions stale until the affected work is reviewed again. Prior outputs and responses remain archived; they are historical evidence, not acceptance of new content. Delivery uses only current reviewed sources named in the accepted complete preview.

## Blocked run without video capability

Moodboard, frames and storyboard are accepted, but gflow is absent. The adapter records a blocked attempt with the prepared shot request and no submission. Present the current packet, its specific missing capability and next setup step; do not generate object animation through code. A failed capability probe does not erase the accepted creative plan. After setup, obtain the required response on that attempt report before another visual generation.
